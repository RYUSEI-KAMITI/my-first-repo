```
def top_words(text, n=3):
    words = text.lower().split()
    counts = {}
    for word in words:
        counts[word] = counts.get(word, 0) + 1
    result = sorted(counts.items(), key=lambda x: (-x[1], x[0]))
    return result[:n]
```

## 2-A バグの原因を予測して確かめる
## 予測
1回目は [2,3],2回目は [2, 3, 10] になると予測した。
## 実際の実行結果
1回目：[2, 3],2回目：[2, 3, 20]
## 自分で見つけたバグ
バグは2個あると考えた。
1. range(len(data) - window) では最後の1区間が計算されない。
2. result=[] をデフォルト引数にしている。
## AIが見つけたバグの数
AIは3個のバグを見つけた。
1. range(len(data) - window) では最後の1区間が計算されない。
2. result=[] をデフォルト引数にしているため、前回の結果が残る。
3. s // window では整数で割り算をするため、期待値のような小数にならない。
## 自分の指摘との違い
自分は2個のバグしか見つけられなかったが、AIは3個見つけた。
自分では、s // window の部分が整数の割り算になっていることに気づくことができなかった。
AIの指摘を見ることで、自分が見落としていた部分を確認することができた。
## 修正版コード
```
def moving_average(data, window=3):
    result = []
    if window <= 0:
        return []
    for i in range(len(data) - window + 1):
        s = 0
        for j in range(window):
            s += data[i + j]
        result.append(s / window)
    return result
print(moving_average([1, 2, 3, 4, 5]))
print(moving_average([10, 20, 30, 40]))
print(moving_average([1, 2, 3], window=0))
print(moving_average([1, 2, 3], window=3))
print(moving_average([1, 2, 3], window=4))
```
